Monitoring

What triggers an alert.

Turn each condition on independently. Stationary and fall detection use your device's real GPS and motion sensors as a stand-in for the cane's own sensors.

No movement, 5+ min

If GPS position hasn't changed meaningfully for 5 minutes, the user may have collapsed or be unable to move.

Off

Sudden impact / fall

A sharp motion spike — consistent with a fall, or the cane being dropped or broken — triggers an immediate alert.

Off

Obstacle ignored

An object stays very close to the cane while the user keeps moving — meaning an alert may have gone unnoticed.

Off
For judges / testing

Waiting 5 real minutes isn't practical for a demo — these fire the same alert flow instantly so the SOS behaviour can be shown live.
